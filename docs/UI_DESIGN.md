# 测试协作平台｜账号界面设计

## T001 登录注册

登录、注册和账号工作台采用暖白底、深绿色主操作和清晰的文字层级。桌面将品牌与表单左对齐，小雀核对测试清单的方幅插画居右。窄屏直接呈现表单，注册按钮在常见手机首屏可见。

登录和注册切换时插画保持原位，旧表单先淡出，新表单随后轻移进入。提交显示进度，字段错误出现在对应输入下方并聚焦首个错误。网络失败保留输入与提交焦点。注册成功时显示勾选反馈，聚焦成功标题并提供返回登录入口，带入刚注册的用户名。系统开启减少动态效果时直接呈现完整状态。

早期状态原型和覆盖清单保存在 [登录注册原型目录](prototypes/login/)。

## T002 账号管理

账号管理与管理员授权共用导航和列表样式。桌面使用侧栏，窄屏使用顶部导航。

两页标题区只显示页面名称，下方直接进入列表。提示用于加载、空列表、错误、操作结果及确认操作时需要知道的影响。

个人账号页集中展示用户名、邮箱、角色和退出登录入口。桌面列表采用细线分隔的四列表格，窄屏将姓名、邮箱及角色状态逐行组织，保留独立的操作入口。普通账号可通过编辑面板查看完整姓名和邮箱。管理员账号在账号管理列表中的操作列留空。

「编辑」在桌面打开居中对话框，在窄屏打开底部面板。角色与状态使用可键盘操作的分段单选控件。开启账号缺少角色时，报错贴近角色字段，标题和保存按钮保持位置。停用已启用的账号时提示所有设备的会话将失效。保存失败保留选择，成功更新当前行并反馈结果。直接进入管理链接时，未登录用户返回登录，无权限用户看到拒绝及返回入口。

## T002 原型评审

服务器操作权限单独决定「管理员授权」入口是否可见。授权页复用账号管理的列表、分页和面板样式。确认框展示目标账号，说明授予管理员会启用目标账号以及现有角色的替换影响。初始焦点放在「取消」，失败反馈显示在确认操作附近，可直接重试。
