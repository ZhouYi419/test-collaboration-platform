# 测试协作平台｜登录注册 UI 设计说明

范围：T001 登录、注册、当前账号及适用的状态；原始设计入口是“prototypes/login/登录注册状态总览.html”，细节参见同目录的状态覆盖清单。项目名称为测试协作平台。

视觉采用深色层次、蓝色高亮、抽象几何构图与紧凑表单。实际页面沿用已确认的视觉方向，桌面并排展示构图与表单，窄屏将构图缩小后移至表单上方。

注册成功后聚焦成功标题并提供返回登录。登录后的账号页展示用户名、邮箱和退出入口。字段校验关联对应输入并聚焦第一个错误，提交期间显示进度，网络失败保留输入以便重试。

2026-11-15 在实际页面验收 Chrome 1440 × 900 和 Edge 390 × 844，核对表单布局与窄屏溢出、键盘焦点、密码显隐、错误提示、网络重试及真实账号流程。完整读屏与 Firefox 兼容性待验证。
