# T002 账号与权限原型

打开 [原型](index.html)。顶部评审栏用于切换模拟身份和状态。账号与会话保存在当前页面内存中，「重置示例」可恢复初始数据。

| 状态或流程 | 操作入口 |
| --- | --- |
| 服务器操作人员授予管理员 | 选「服务器操作人员」，为「吴晨」点「授予管理员」。确认后该账号成为管理员并启用。选择已有角色的账号可查看角色替换提示。 |
| 无权限时隐藏入口并拒绝直达 | 切换至「管理员」「普通用户」或「T001 旧账号」，在评审栏点「直达授权页」。 |
| 未登录访问 | 切换至「未登录」后点「直达授权页」，显示登录提示。 |
| 管理员编辑普通账号 | 切换至「管理员」，编辑「吴晨」，测试无角色时启用的校验，再分配测试或开发角色并保存。 |
| 停用与重新启用 | 以管理员身份停用「赵庭」，切换至「普通用户」查看停用提示。再以管理员身份启用该账号，切回普通用户后需点击「重新登录」。 |
| 历史账号 | 切换至「T001 旧账号」，查看用户名、邮箱及「未分配」角色。 |
| 提交中、失败、重试和空状态 | 在列表切换「保存失败」，授权或编辑后可重试。切换「列表为空」可查看空状态。 |

已在 Chrome 1440 × 900 和 Edge 390 × 844 渲染和操作，并检查 320 像素宽度的授权列表。核对了对话框初始焦点、Escape、长邮箱换行和保存结果。

入口权限和会话行为在原型中以模拟数据展示。真正的页面鉴权、接口 401 和 403、服务器操作权限的身份绑定与会话撤销将在产品实现后验证。
