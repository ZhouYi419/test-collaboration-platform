# T007 事项查询与逐轮历史原型

从[我的事项](index.html#tester)搜索 `csv`，可同时筛选「Bug 修复」「P1」「已关闭」。打开结果并展开「处理与验证历史」，查看两次退回和最后一次通过分别对应的反馈。

| 场景 | 入口 | 可检查的结果 |
| --- | --- | --- |
| 测试查询与组合筛选 | [我的事项](index.html#tester) · [组合查询](index.html#tester?q=csv&type=bug&priority=P1&status=closed) | 按标题或详细描述搜索，输入回车和点击查询等效。类型、优先级、状态可叠加。 |
| 三种排序与分页 | [第一页](index.html#tester) · [第二页](index.html#tester?page=2) | 默认最近更新，可切换到最早更新或优先级从高到低。改变条件回第一页，从详情返回恢复查询、页码和原行。 |
| 开发队列权限 | [待领取](index.html#developer?queue=inbox) · [我的待办](index.html#developer?queue=assigned) · [已反馈](index.html#developer?queue=feedback) | 查询在当前队列生效。已反馈提供「待验证」和「已关闭」，待领取只有一个状态。 |
| 已关闭历史 | [两次退回后关闭](index.html#tester/report?history=1) | 最新一轮在前，每轮内先反馈后验证。可核对开发人、验证人、时间、结果和原因。 |
| 待验证与处理中 | [等待复验](index.html#tester/copy?history=1) · [已退回](index.html#developer/retry?queue=assigned&history=1) | 新反馈显示为待验证的一轮。已退回且仍在处理时，同一份反馈只出现一次。 |
| 空态 | [无匹配](index.html#tester?q=不存在的标题) · [空队列](index.html?case=empty#developer?queue=assigned) · [无历史](index.html#developer/snapshot?queue=assigned&history=1) | 区分筛选无匹配、队列为空和事项尚无历史。无匹配时提供清空条件。 |
| 加载、失败与恢复 | [加载提示](index.html?case=loading#tester) · [列表读取失败](index.html?case=list-error#tester?q=csv&type=bug) · [历史读取失败](index.html?case=history-error#tester/report?history=1) | 重试保留原查询。历史重试成功后聚焦最新一轮，失败反馈位于对应区块。 |
| 访问受限 | [非负责开发](index.html#otherdev/report?queue=assigned&history=1) · [其他测试](index.html#colleague/report?history=1) · [待领取详情](index.html#developer/edge?queue=inbox&history=1) | 无关账号无法查看受限详情。开发可打开待领取详情，历史入口仅对提交人和负责人可用。 |

## 浏览器复审

- Chrome 1440 × 900 验证标题和描述命中、组合条件、三种排序、末页、清空条件、从第二页返回恢复、键盘展开及逐轮顺序。列表和详情外框在同视口左右对齐。
- Edge 390 × 844 实际打开状态下拉，核对展开样式、方向键和 Enter 选择、当前队列选项和待验证历史。320 × 740 验证长原因、列表和历史失败重试、焦点、空态及无权直达。
- 复审发现历史标题靠近视口底部时，展开后只能看到少量内容。调整为在这种情况下把标题移到视口内，复拍时能看到首轮内容。代表性截图无横向溢出。

原型使用模拟数据和模拟请求。真实 API 的查询、分页、历史关联和权限在实现阶段验收。实体手机软键盘、Firefox 和完整读屏待验收。
