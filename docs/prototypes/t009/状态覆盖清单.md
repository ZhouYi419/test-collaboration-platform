# T009 统计看板原型

从[测试看板](index.html#tester)进入，或在页尾切换开发和管理员视角。图表和状态数量使用模拟数据。

| 场景 | 入口 | 可检查的结果 |
| --- | --- | --- |
| 测试看板 | [测试](index.html#tester) | 当前待办突出「待验证」，状态分布仅包含本人提交的事项。点击状态进入对应的「我的事项」筛选，返回保留日期选择和入口焦点。 |
| 开发看板 | [开发](index.html#developer) | 「我的待办」包含待处理和处理中。共享待领取单独显示，进入已有的待领取队列。状态分布和近期进度只用本人负责的事项。 |
| 管理员看板 | [管理员](index.html#admin) | 汇总全站已提交事项。未关闭数量可按待领取、待处理或处理中、待验证核对。汇总区没有进入事项详情的入口。 |
| 近期进度 | [日期选择](index.html#tester) | 可切换最近 7 天、最近 30 天或自选日期。处理反馈、验证通过、验证退回分别计数。切换日期时上方当前待办和状态分布保持原口径。 |
| 自选日期与校验 | [自选日期](index.html#tester) | 开始和结束可为同一天。日期缺失、结束早于开始或选择未来日期时，在表单里提示。过去没有记录的时间段显示空状态。长区间合并为不超过 31 个日期段。 |
| 图表明细 | [近期进度](index.html#tester) | 可点柱组查看对应日期。键盘用方向键、Home 和 End 切换。「查看数据」可按日期或日期段逐行核对。 |
| 加载、空、失败和重试 | [加载中](index.html?case=loading#tester) · [空状态](index.html?case=empty#tester) · [读取失败](index.html?case=error#tester) · [切换日期失败](index.html?case=range-error#tester) | 首次读取失败可重试。切换日期失败时保留原选区间，其他统计仍可查看。零待办及无活动均显示明确状态。 |
| 权限受限 | [未分配角色](index.html#unassigned) | 顶栏隐藏看板入口，直接进入时提示联系管理员。 |

## 浏览器复审

- Chrome 1440 × 900 检查三种角色的导航、范围和指标。验证日期切换、键盘操作图表、数据表展开、进入既有列表的模拟跳转及返回焦点。960 × 780 验证中间宽度无溢出。
- Edge 390 × 844 和 320 × 740 验证自选日期、单日、长区间、无记录日期、错误提示和重试。实际打开窄屏原生日期选择器并截图。检查 30 天柱组和日期标签，确认页面无横向溢出。
- 复审后将当前待办和状态分布合并在同一表面。320 像素下两个日期控件改为上下排列，复拍确认日期输入、应用按钮及校验提示可见。
- 真实聚合、跨角色权限、北京时间跨日边界和真实队列跳转在产品实现阶段验收。Firefox、实体手机日期选择器和完整读屏待实测。
