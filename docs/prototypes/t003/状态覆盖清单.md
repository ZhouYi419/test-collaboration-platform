# T003 我的事项原型

用浏览器打开 [index.html](index.html)。示例账号为测试人员林溪。记录和所选附件保存在当前页面内存，刷新会恢复示例数据。日期时间按北京时间显示。

| 状态或流程 | 操作入口 |
| --- | --- |
| 列表和详情 | 默认列表含两类已提交事项、长标题及未命名草稿。点击首条进入只读详情，可下载示例日志。 |
| 新建和校验 | 点「新建事项」，直接点击提交查看缺少类型和公共字段的提示。选择 Bug 修复或需求，分别体验专属字段及校验。 |
| 优先级和发生环境 | 两种表单均可选择 P0–P3，Bug 可选择 dev、uat、prd。保存或提交后可在列表查看优先级，在 Bug 详情查看发生环境。 |
| 草稿 | 填写部分内容或保留空白，点击「保存草稿」。从列表重新打开，继续编辑或补齐后提交。 |
| 直接提交 | 填完公共及类型必填字段，点击「提交事项」。返回列表后打开新记录，查看「待领取」状态和只读字段。 |
| 删除和离开 | 编辑草稿，点击「删除草稿」，分别体验取消和确认。修改内容后点返回，体验放弃修改确认。 |
| 附件 | 在新建或草稿中选择本地文件，查看名称、大小、移除和下载。尝试选择超大文件或超过 5 个附件。可在系统文件选择器切换显示类型来选择不支持的文件。 |
| 空、加载和列表失败 | [空列表](index.html?state=empty) · [加载中](index.html?state=loading) · [列表失败与重试](index.html?state=list-error)。 |
| 写入失败 | [写入失败与重试](index.html?state=write-error)。首次保存、提交或删除模拟网络失败，再次操作可成功。 |
| 权限和会话状态 | [开发角色直接访问](index.html?state=forbidden#issue-5) · [会话失效](index.html?state=expired#issue-5) · [事项不可用](index.html#issue-999)。 |

原型暂用「致命、严重、一般、轻微」表示严重程度。标题上限暂为 100 字符，多行字段上限 5,000 字符，其他短文本上限 120 字符。原型接受 JPG 的常见扩展名 `.jpeg`，以 10,000,000 字节作为 10 MB 上限。

已在 Chrome 1440 × 900 和 Edge 390 × 844 渲染并操作，另外检查 Edge 320 像素宽度下的列表和表单溢出。浏览器验证覆盖 Bug 直接提交、需求草稿续编和提交、附件边界及下载、校验焦点、模拟权限、失败后重试、删除确认和 Escape 关闭。

本轮复测了两组下拉选项、键盘选择发生环境、列表整行点击、返回时恢复滚动与焦点、类型切换时公共字段不移位，以及减少动态效果模式。

附件校验模拟扩展名、数量和大小限制。真实鉴权、文件内容校验、数据库持久化、事务和失败回滚在产品实现后验证。
