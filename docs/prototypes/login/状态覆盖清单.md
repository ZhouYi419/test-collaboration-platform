# 登录注册 UI 状态覆盖清单

查看入口：登录注册状态总览.html。顶部状态选择器属于原型查看工具，不是产品页面；单独打开可查看无选择器的页面。所有账号、请求和结果均为模拟，不连接后端。

## 已提供的画面
- 登录：初始、必填提示、密码显示、提交中、用户名或密码错误、账号未启用、网络失败。
- 注册：初始、必填提示、邮箱格式错误、密码少于 8 位、两次密码不一致、用户名重复、邮箱重复、提交中、网络失败、注册成功等待管理员启用。
- 从注册返回登录；密码显隐、表单基础校验可在交互原型操作。状态总览的提交中等固定画面可切换查看，不代表真实网络请求。

## 说明与未决项
- 唯一性、启用状态和真实凭据由后端验证；原型中的错误反馈只是样式展示，输入数据不会被保存。网络错误保留输入并允许重试是设计建议，需以实际功能验证。
- 登录成功后的目的页面、退出方式、账号禁用与首次管理员创建方式尚未确认；这些结果未设计为具体页面或既定业务规则。注册不验证邮箱，也没有部门字段。
- 若用户名和其他用户邮箱可能重合，登录标识的冲突规则仍待确定。错误提示文案及具体校验时机为设计建议。
- 页面状态和布局尚未在浏览器实际渲染；之前本地文件预览被浏览器安全策略阻止。桌面、窄屏、键盘及读屏验收均待完成。静态脚本语法和状态清单的映射可做本地检查，不能替代实际渲染验收。
